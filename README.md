# 🇩🇿 DZ-Estate — Real Estate Platform

**DZ-Estate** is a real estate platform project designed to connect property sellers and buyers or renters in Algeria. It aims to simplify property listing management and help users find properties that match their needs.

## 📌 Project Overview

The platform is designed to provide a centralized space where individuals and real estate agents can publish and manage property listings, while potential buyers and renters can explore available properties and interact with sellers.

This project was developed as part of an academic team project at the École Supérieure en Sciences et Technologies de l’Informatique et du Numérique (ESTIN).

## ✨ Key Features

- **User Management:** Store user information and support both client and seller roles.
- **Property Listings:** Manage property descriptions, prices, surface areas, room counts, and locations.
- **Search Alerts:** Define property criteria based on price, location, surface area, and number of rooms.
- **User Interactions:** Support likes, comments, and saved properties.
- **Messaging System:** Enable communication between clients and property sellers.
- **Media Management:** Associate photos and videos with property listings.
- **Transaction Tracking:** Manage property sale and rental statuses.
- **Database Operations:** Perform CRUD operations (Create, Read, Update, Delete) using SQL.

## 🗄️ Database Design

The database design covers the main entities and relationships required by the platform, including:

- Users, clients, and sellers
- Properties and their associated media
- Messages and attached files
- Likes, saved properties, and comments
- Personalized property alerts
- Property transaction history

The project also includes business rules for property locations, user roles, notifications, and transaction status management.

## 🛠️ Technical Work

The documented database work includes:

- Entity-Relationship (ER) modeling
- Entity and relationship dictionaries
- Database constraints and relationships
- Primary keys and foreign keys
- SQL queries for inserting, retrieving, updating, and deleting records
- Business rules and derived information

## 🎯 Project Goals

- Improve the visibility of real estate listings in Algeria.
- Simplify interactions between property sellers and potential buyers or renters.
- Organize property information in a structured relational database.
- Provide a foundation for property search and personalized alerts.
